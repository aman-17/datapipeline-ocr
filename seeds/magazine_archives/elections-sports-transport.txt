# Format: <index-page-url> | <licence> | <label> | follow=<regex>
# The line is split on "|", so a follow regex can never contain alternation.
# Every seed below was probed with the adapter's own HREF/looks_like_pdf_url/
# RobotsCache path at 1 req/s: index fetched, PDF links counted, one PDF
# fetched (HTTP 200, %PDF- magic) and checked with pymupdf for a text layer
# (>= 30 words on page 1 or the first table page) and find_tables hits.
# All samples were born-digital (no image-only pages seen).
#
# Run:  uv run python -m scriptocr discover magazine_archives --query seeds/magazine_archives/elections-sports-transport.txt
#
# Host notes:
#   results.imsa.com 302s to imsa.results.alkamelcloud.com and the listing uses
#     RELATIVE hrefs; the adapter joins against the seed URL (not the redirect
#     target), so the seed MUST be the alkamelcloud host or every PDF URL is
#     minted on the wrong host (results.imsa.com/Results/... then 302s to a
#     malformed "https://imsa.results.alkamelcloud.comResults/..." URL).
#   www.sos.ca.gov issue pages link PDFs on elections.cdn.sos.ca.gov (another
#     host; fine — only follow links are host-restricted). Each issue page links
#     both complete-sov.pdf (~13 MB) and the per-section PDFs it is made of, so
#     the compiled volume duplicates its own sections (BIS qtrpdf-style hazard).
#   www.trenitalia.com In_Treno_Orario_TuttItalia.pdf is 53 MB / 3,768 pages —
#     under the 128 MB cap but slow; only 4 timetable PDFs on that page (kept
#     commented out below as optional).
#   Licence column is blank wherever the site states no reusable licence.
#     bundeswahlleiterin.de impressum: reproduction permitted with attribution
#     ("Quellenangabe ist jedoch erforderlich") — not asserted as open.
#     mext.go.jp states its Government Standard Terms of Use are CC BY 4.0-
#     compatible; soumu.go.jp's terms page could not be confirmed by grep, so
#     soumu stays blank.
