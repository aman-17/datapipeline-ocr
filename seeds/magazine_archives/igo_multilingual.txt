# magazine_archives seeds — group "igo-multilingual" (validated 2026-09-10)
#
# Intergovernmental-organisation publication archives whose raw HTML carries
# .pdf hrefs (or one hop of issue pages that do). Every line below was checked:
# index fetched with curl/httpx under the pipeline User-Agent, robots.txt allows
# the index, the hop pages and the PDF paths for our UA (scriptocr RobotsCache),
# and one PDF per line was downloaded, %PDF- checked and inspected with pymupdf
# (text layer >= 30 words, tables found with find_tables(strategy="text")).
#
# Format: <index-page-url> | <licence> | <label> | follow=<regex>
# The adapter splits a line on "|" BEFORE it reads follow=, so a follow regex
# must not contain "|" (no alternation) — use character classes, optional
# groups, or one line per alternative instead.
# Licence is only asserted where the publisher states it on the site or on the
# copyright page of the sampled PDF; blank otherwise.
#
# Run:  uv run python -m scriptocr discover magazine_archives --query seeds/magazine_archives/igo_multilingual.txt
#
# Politeness notes for the operator: none of these hosts publishes a
# Crawl-delay; www.imf.org /external/ answers plain requests while /en/ is
# WAF-gated, so keep the IMF lines on the legacy /external/ paths only.

# --- economics / finance ---------------------------------------------------
# ECB Economic Bulletin, every issue 2015-01..2026-05 in up to 24 EU languages
# (175 PDFs on the page: 99 en + de/es/fr/it/lt/lv/et/pt/... editions).
# ECB copyright notice: free use with the ECB cited as source — not a named licence.
https://www.ecb.europa.eu/press/economic-bulletin/html/all_releases.en.html | | ecb-economic-bulletin

# AfDB African Economic Outlook family: 2026 Country Focus Reports in en/fr/pt
# (country-focus-report-2026-*, rapport-pays-2026-*, relatorio-de-foco-do-pais-2026-*)
# and the regional outlooks (*-economic-outlook-2026); one PDF per document
# page. Paginated (?page=1..) — add a line per page if more depth is wanted.
https://www.afdb.org/en/documents/publications/african-economic-outlook | | afdb-aeo-country-reports | follow=/documents/[a-z-]+-20\d\d(-[a-z-]+)?$

# EIB publications (fr index): each publication page links the report and its
# language editions — "EIB at a glance" alone is 43 PDFs in ~30 languages.
https://www.eib.org/fr/publications/index | all rights reserved | eib-publications-fr | follow=/fr/publications/\d{8}-[^/?]+$

# BCEAO (WAEMU central bank, French): the five "Rapport sur la politique
# monétaire" PDFs linked directly from the publications index (dense
# statistical tables). Low volume: the per-theme listings are filter views that
# expose no further PDFs in raw HTML.
https://www.bceao.int/fr/publications | | bceao-publications-fr

# IMF Finance & Development magazine — legacy /external/ archives with direct
# article/issue PDFs. French archive: 103 PDFs on the page. Chinese archive: 43
# direct + one hop into per-issue index pages.
https://www.imf.org/external/pubs/ft/fandd/fre/fda.htm | all rights reserved | imf-fandd-fr
https://www.imf.org/external/chinese/pubs/ft/fandd/fda.htm | all rights reserved | imf-fandd-zh | follow=/chinese/pubs/ft/fandd/20\d\d/\d\d/index\.htm$

# Eurasian Economic Commission statistics (Russian): info-blocks on the index
# plus yearbook / pocketbook / express-information sub-pages (426-page
# Statistical Yearbook 2025 is wall-to-wall tables). Anchored to the Russian
# path so the /ky/ /hy/ /be/ mirrors of the same pages are not re-visited.
https://eec.eaeunion.org/comission/department/dep_stat/union_stat/publications/ | | eaeu-statistics-ru | follow=^https://eec\.eaeunion\.org/comission/department/dep_stat/union_stat/publications/[a-z_]+/[A-Za-z0-9_-]+\.php$
